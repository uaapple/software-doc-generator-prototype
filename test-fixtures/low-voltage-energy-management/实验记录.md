# 低压能量管理 SLX + Hermes 生成对齐实验记录

## 目标

使用当前系统真实链路解析 `HvCoorn.slx`，结合系统需求、人工标题框架和相关 skill，通过 Hermes agent 生成软件需求，并与 `低压能量管理软件需求范例.md` 对齐。

## 隔离约束

- 生成结果、MRV/解析产物、对比报告和候选优化先保存在本测试目录。
- 暂不直接修改 `src/`、`skills/active/`、真实工程数据里的系统实现或 active skill。
- 若发现需要系统级优化，先在 `candidate-optimizations/` 下记录候选补丁/策略，验证通过后再决定是否合入真实系统。

## 产物目录

- `artifacts/`：本轮解析、生成、对比等运行产物。
- `candidate-optimizations/`：候选优化策略、prompt 草案、skill 草案或补丁说明。

## 验收报告要求

如果最终生成结果判断为基本达标，需要在本目录生成 HTML 报告：

- 左右并列展示 Hermes 生成的软件需求和人工软件需求范例。
- 说明为什么认为已经达标，包括标题框架、核心条件、阈值、状态输出、退出动作、失败计数和复位逻辑的覆盖情况。
- 如仍存在轻微差异，需要明确列出残余差异和不影响达标的理由。
