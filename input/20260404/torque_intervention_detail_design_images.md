## 4 软件需求

### 4.1 ESP干预前轴状态判断

**SMiVCU-2797 - 需求名称：** ESP干预前轴状态判断

**需求描述：**

当满足以下任意条件时，`<前轴扭矩干预激活标志位>` 为 1：

- `<前轴RBS扭矩激活标志位>` 为 1，且 `<RBS需求前轴扭矩> >= tqESCIntvMin`（标定量，初始值 -3700）且 `<= tqESCIntvMax`（标定量，初始值 3700）；将前轴RBS干预激活置 1；
- `<前轴降扭激活标志位>` 为 1，且 `<前轴降扭目标扭矩> >= tqESCIntvMin` 且 `<= tqESCIntvMax`；将前轴降扭干预激活置 1；
- `<前轴升扭激活标志位>` 为 1，且 `<前轴升扭目标扭矩> >= tqESCIntvMin` 且 `<= tqESCIntvMax`；将前轴升扭干预激活置 1；

否则，`<前轴扭矩干预激活标志位>` 为 0。

### 4.2 ESP干预前轴扭矩计算

**SMiVCU-2799 - 需求名称：** ESP干预前轴扭矩计算

**需求描述：**

当 `<前轴升扭干预激活>` = 1 时，

- `<ESC干预后的前轴目标扭矩> = <前轴升扭目标扭矩>`；

否则，当 `<前轴降扭干预激活>` = 1 时，

- `<ESC干预后的前轴目标扭矩> = <前轴降扭目标扭矩>`；

否则，当 `<ABS激活标志位>`、`<EBD激活标志位>`、`<AEB激活标志位>`、`<CDP激活标志位>` 任一为 1 时，

- `<ESC干预后的前轴目标扭矩> = 0`；

否则，当 `<APA激活标志位>` 或 `<ACC激活标志位>` 为 1，且 `<泊车请求扭矩有效>` 为 1 时，

- `<ESC干预后的前轴目标扭矩> = <仲裁后的前轴目标扭矩>`；

否则，当 `<前轴RBS干预激活>` = 1 时，

若 `<RBC控制模式状态> >= VehCfg_stRBCCtrlModeESPCtrlSplt_SC(3)`，

- `<ESC干涉的滑行回收前轴目标扭矩> = min（<ESC干涉的滑行回收前轴目标扭矩> + <RBS需求前轴扭矩>，0）`；

若 `<RBC控制模式状态> ≠ VehCfg_stRBCCtrlModeESPCtrlSplt_SC(3)`，

- `<ESC干预后的前轴目标扭矩> = min（<仲裁后的前轴目标扭矩>，0）`；

否则，

- `<ESC干预后的前轴目标扭矩> = <仲裁后的前轴目标扭矩>`；

其中，`<ESC干涉的滑行回收前轴目标扭矩>` 的计算方法为：

- 当 `<前轴RBS扭矩激活标志位>` 为 0 时，`<ESC干涉的滑行回收前轴目标扭矩>` 为 `<仲裁后的前轴目标扭矩>` 与 0 取小值；
- 当 `<前轴RBS扭矩激活标志位>` 为 1 时，`<ESC干涉的滑行回收前轴目标扭矩>` 为上一时刻的 `<仲裁后的前轴目标扭矩>` 与 0 取小值。

注：`<ESC干预后的前轴目标扭矩>` 要经过 `<前轴最大允许扭矩>` 和 `<前轴最小允许扭矩>` 限制后得到。

**SMiVCU-10334 - 计算前轴仅RBS激活标志位：**

当以下条件全部满足时，将 `<前轴仅RBS激活标志位>` 置 1，否则置 0：

- `[前轴升扭干预激活] = 0`；
- `[前轴降扭干预激活] = 0`；
- `<ABS激活标志位>`、`<EBD激活标志位>`、`<AEB激活标志位>`、`<CDP激活标志位>` 全部为 0；
- `[前轴RBS干预激活] = 0`；
- `<APA激活标志位>` 且 `<ACC激活标志位>` 为 0，或 `<泊车请求扭矩有效>` 为 0。
