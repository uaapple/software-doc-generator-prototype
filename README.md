# 软件开发需求自动生成原型

这是第一阶段的内网 Web 原型，实现了以下闭环：

- 创建项目并上传系统需求 PDF、模型 PDF、生成 C 文件
- 对 PDF 和 C 文件做基础抽取
- 通过后端 LLM 编排层生成结构化软件开发需求条目
- 对生成结果做规则校验
- 在前端页面中查看、追溯、接受、修改或驳回需求

## 运行方式

1. 安装依赖
2. 可选：配置 `OPENAI_API_KEY` 与 `OPENAI_MODEL`
3. 启动服务：`npm start`
4. 打开 `http://localhost:3000`

## 环境变量

- `PORT`: 服务端口，默认 `3000`
- `OPENAI_API_KEY`: 大模型 API Key
- `OPENAI_MODEL`: 模型名，默认 `gpt-4.1-mini`
- `OPENAI_BASE_URL`: 可选，自定义兼容 API 地址

## 当前范围

- `slx` 文件只做上传和接口预留，第一阶段不直接解析
- 以结构化需求条目为主，正式文档导出留待下一阶段
- 未配置 LLM API 时，系统自动回退到本地规则模式，便于演示和联调
